# Titanic-Dataset-Preprocessing
Data cleaning and preprocessing of the Titanic dataset using Python and Pandas in Google Colab.

Project Overview

This project focuses on cleaning and preprocessing the Titanic dataset using Python and Pandas in Google Colab.

The aim is to explore the dataset, identify missing values, perform data cleaning and prepare the data for further analysis.

Tools & Technologies

- Python
- Google Colab
- Pandas
- NumPy

Dataset

Titanic Dataset – Kaggle

Steps Performed

1. Loaded the Titanic dataset.
2. Explored rows, columns and data types.
3. Analysed passenger gender and survival.
4. Calculated survival percentages by gender and passenger class.
5. Identified missing values.
6. Filled missing Age values using the mean.
7. Filled missing Embarked values using the mode.
8. Replaced missing Cabin values with "Unknown".
9. Encoded Sex column (Male = 1, Female = 0).
10. Performed correlation analysis.

Project Files

- "Titanic_Dataset_Preprocessing.ipynb" – Complete Python notebook.
- "Titanic_Cleaned.csv" – Preprocessed dataset.

Conclusion

This project helped me understand the importance of data cleaning, handling missing values, encoding categorical data and exploring datasets using Python.
